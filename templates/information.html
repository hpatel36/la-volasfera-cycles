Methodology

How station events are calculated and projected onto each timeline.

Reference and anchor

The reference is the birth, event or radix moment from which a cycle is measured. The anchor is the period the user wants to inspect. Both are interpreted as Universal Time (UTC).

True Node stations

The application calculates True North Node longitude and speed on demand with Swiss Ephemeris. A station is refined where longitudinal speed changes sign, then its UTC time is rounded to the nearest second. The supported source range is 1400 through 2100.

The default selector samples consecutive UTC-day boundaries, omitting most short direct/retrograde pairs that occur within one UTC day. A small number of edge cases identified during full-range validation are handled explicitly. This is the event-selection method used by the explorer, not a claim to list every mathematical speed reversal; the code also contains an exhaustive scanner for technical inspection.

Cycle projections

For a source station S and reference R, a direct event is R + (S − R) × factor. A converse event mirrors the source interval: R + (R − S) × factor.

Node Transit Converse
Factor 1; the station interval is reflected around the reference.
Secondary Progression
Factor 365.242199074074; approximately one ephemeris day represents one tropical year.
Tertiary Progression
Factor 29.530588857; one synodic lunar month is used as the projection factor.
Minor Progression
Factor 12.368266432; the monthly-to-yearly ratio is used as the projection factor.

Converse timelines are shown by default. Direct secondary, tertiary and minor progressions are optional comparisons; there is no direct Node Transit timeline.

Validation and interpretation

Automated validation covers the supported 1400–2100 range, comparing timestamps to within one second and requiring exact positions and directions.

La Volasfera images are selected from the station's zodiac degree. Astrology is an interpretive tradition; the results are not scientific, medical, legal or financial advice.

Sources

Primary texts, software and ephemeris data used by the application.

La Volasfera symbolic degrees

The images and interpretations were transcribed from Charubel and Sepharial, The Degrees of the Zodiac Symbolized (1902). The La Volasfera text is attributed in that edition to Sepharial (Walter Gorn Old, 1864–1929).

Read the 1902 digital scan.

The source edition is in the public domain. The structured transcription contains La Volasfera material only; it does not contain Sabian symbols or modern third-party commentary.

Swiss Ephemeris

True Node calculations use Swiss Ephemeris through the pysweph Python package. The two required lunar files are downloaded from official Swiss Ephemeris commit b51a083390bf3cdc93a6ba466cbc83b846c4cfc4 and verified against pinned SHA-256 hashes during deployment.
